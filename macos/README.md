# 为 *Chill with You: Lo-Fi Story* 添加网易云音乐与 Apple Music —— Mac 版

在 Mac 上也能让聪音陪你听自己的歌啦！

保留原插件的网易云、Apple Music 和本地音乐三个音源，把 Windows 专属的部分适配到 macOS。\
配置好后，直接在 **Steam 点击“开始游戏”**，就会自动加载 Mod，不需要另外打开启动器。

当前版本：**1.2.0.4，实验适配版**。已在 M1 Pro 上测试，网易云和 Apple Music 可用；优化后，测试者反馈流畅度明显改善。

## Mac 适配新增

- **Apple Music 真实进度拖动**：拖动游戏里的进度条，会直接改变“音乐”App 中歌曲的实际播放位置，不只是移动界面上的滑块。原 Windows 版说明中的 Apple Music 不支持拖动进度，这里已补上。
- **整个游戏无声时的恢复功能**：针对 macOS 音频设备切换后 Unity 可能进入无声输出的情况，增加限次自动恢复和 **“修复游戏声音”** 按钮。会尝试保留网易云曲目、进度和暂停状态；设备或驱动持续不可用时，仍可能需要重新启动游戏。
- **Steam 直接启动 + Apple 芯片原生运行**：配置一次后照常点击“开始游戏”，无需额外启动器；减少转译和不必要的后台刷新。

## 安装

**已经配置好 Steam 启动？直接开始游戏即可，不用重复安装。**

首次安装：

1. 先在 Steam 安装 Mac 版游戏。
2. 把本项目放到一个固定位置，例如“文稿”文件夹。当前提供的是源码，首次使用需要先完成文末的 [构建步骤](#从源码构建)。
3. 正常退出游戏和 Steam，在项目根目录打开终端，执行：

   ```sh
   python3 macos/tools/steam_options.py install
   ```

4. 重新打开 Steam，点击“开始游戏”。进入游戏的音乐面板，就能选择网易云、Apple Music 或本地音乐。

安装工具会备份原来的 Steam 启动选项；如果已经设置了其他启动参数，它会提示并停止，不会直接覆盖。

⚠ **安装后不要随意移动或删除项目文件夹**，Steam 需要通过这个位置找到 Mod。也不需要把 Windows 版的文件复制进游戏目录。

项目里的 `启动音乐Mod.command` 保留作备用入口，平时不需要打开。

## 功能

**网易云音乐**

- 使用自己的账号扫码登录
- 查看歌单、搜索歌曲、播放音乐和滚动歌词
- 播放、暂停、切歌、音量与进度控制
- 登录信息保存在 macOS 钥匙串中，下次启动可自动恢复

首次保存或读取登录信息时，系统可能询问钥匙串访问权限。

**Apple Music**

- 连接 Mac 自带的“音乐”App，读取资料库中的歌单和歌曲
- 支持播放控制、音量和进度调整
- 音乐窗口可以最小化，不需要一直放在前台
- 保留原插件的网易云歌词匹配功能

⚠ 请先在“音乐”App 中登录自己的账号，并保持它运行。首次连接时，如果系统询问是否允许控制“音乐”，请允许。**歌曲封面目前仍显示占位图。**

**本地音乐与通用功能**

- 保留游戏自带音乐和本地导入曲目的播放功能
- 保留原插件的解除导入上限、按需加载和列表优化
- 三个音源分开管理，切换时让其他音源暂停
- 使用游戏底部播放条控制音乐

大量本地曲目导入还没有做完整压力测试，建议先用少量歌曲试用。

## 运行与流畅度

- Apple 芯片 Mac 使用原生方式运行，不再强制通过 Rosetta 转译
- 减少不必要的界面刷新和后台查询
- 不降低游戏画质，不修改原游戏程序

已测试机器为 **M1 Pro / macOS 26.5.2**，游戏版本 **1.16.1**。Intel Mac 尚未实机验证。流畅度改善来自实际试用反馈，没有测量具体帧率提升；长期稳定性仍需持续验证。

和原插件一样，游戏更新、音乐 App 更新或网易云接口变化，都可能影响使用。歌曲能否播放仍取决于账号订阅、版权和地区，不会绕过 VIP 或 DRM 限制。

## 已知情况：整个游戏突然没有声音

在 macOS 上切换或重新连接耳机、蓝牙、HDMI/USB 等音频设备后，Unity 的音频引擎有时会初始化失败。此时可能出现 **歌曲进度条仍在走，但网易云音乐和游戏本身的声音都消失** 的情况。

本机已在日志中观察到 Unity/FMOD 的输出设备初始化失败，以及退回无声输出模式。这属于游戏音频引擎与 macOS 输出设备切换时的兼容问题，不代表歌曲加载失败，也不等于所有 Mac 都会发生。

1. 先确认 macOS 当前选择的是你想使用的输出设备。
2. 音频恢复版仅在检测到明确的无声输出错误后延迟尝试恢复，一分钟内最多三次，避免不停重置。
3. 如果仍无声，打开游戏的 **音乐/歌单面板 → 展开 Mod 区域**，在 **音源标题下方、连接账号区域上方** 找到 **“修复游戏声音”** 按钮并点击。达到次数限制后，请等一分钟再试。
4. 如果仍未恢复，保存并正常退出游戏，再从 Steam 重新启动。

恢复时不更改系统音量、不切换系统输出设备；会尝试重新连接 Unity 音频，并保留网易云当前曲目、进度和暂停状态。设备或驱动持续不可用时不能保证自动恢复。外部“音乐”App 的输出由系统管理，此按钮只修复游戏内音频。

## 停用与卸载

1. 正常退出游戏和 Steam。
2. 在项目根目录打开终端，执行：

   ```sh
   python3 macos/tools/steam_options.py restore
   ```

3. 之后再从 Steam 启动，就会回到原版。如果不再需要 Mod，可以删除项目文件夹。

⚠ **先恢复启动选项，再删除文件夹**，否则 Steam 会找不到启动文件。

删除文件夹不会自动清除网易云的钥匙串记录。如需完整退出账号，请先在 Mod 内退出登录。

## 关于数据与隐私

- 不替换游戏程序；接入 Steam 时，只修改本游戏的启动选项并保留备份
- 网易云登录信息存放在 macOS 钥匙串，不明文保存到文件
- 配置、日志和音乐缓存留在本地；游戏继续使用自己的存档
- **不要直接分享已经用过的整个项目文件夹**：运行目录和备份里可能包含私人歌单、日志及账号相关信息

## 从源码构建

<details>
<summary>首次构建或继续开发时，展开这里</summary>

需要安装 **.NET SDK 8**，并已通过 Steam 安装 Mac 版游戏。配置 Steam 的工具还需要 **Python 3**。构建时会读取本机游戏文件，不会把游戏文件打包进 Mod。

先正常退出游戏，在项目根目录打开终端，执行：

```sh
./macos/build.sh
```

完成后，运行文件位于 `macos/dist/ChillMusicMac`。再按上面的安装步骤接入 Steam 即可。构建完成后，日常启动不需要 .NET SDK，也不需要 Windows 或 Wine。

如果 SDK 不在默认位置：

```sh
DOTNET_BIN=/absolute/path/to/dotnet ./macos/build.sh
```

如果游戏不在默认 Steam 库，构建时用 `CHILL_GAME_APP` 指定游戏 `.app` 的完整路径。不要在游戏运行时重新构建到它正在使用的目录；需要边运行边构建时，可用 `MUSICBRIDGE_BUILD_DEST` 指定其他输出目录。

本地测试：

```sh
dotnet run --project macos/tests
python3 -m unittest discover -s macos/tools -p 'test_*.py'
```

可选系统接口测试（读取音乐库、匿名联网，钥匙串使用独立临时测试条目）：

```sh
dotnet run --project macos/tests -- --music --network --keychain
```

撤销最近一次通过升级工具安装的版本：退出游戏后，在项目根目录执行 `python3 macos/tools/runtime_update.py rollback`。它需要已有的本地备份，不会删除音乐缓存；如果要回到不支持 Steam 接入的旧版本，请先恢复 Steam 启动选项。

测试结果见 [测试记录](TEST-REPORT.md)，运行库来源、构建修改和许可见 [原生运行库说明](NATIVE-RUNTIME.md)。当前 ARM 兼容运行库来自社区分支，不代表 BepInEx 官方稳定版支持承诺。
